# Глава III — Эхо руин

## Файлы
- `src/quests/quests.ts` — `quest_ruins_001`
- `src/quests/npc.ts` — диалоги старосты

## Цепочка
1. Поля → 2. Кабан → 3. Гоблины → 4. Главарь → 5. 3 кристалла → **6. Руины (5 нежити)**

## Условия входа
- Уровень **≥ 15** (`progression.ts`)
- Первый убитый Главарь гоблинов (блок пещера → руины в App)
- Квест «Осколки Тьмы» сдан

## Как проверить
1. Сдать кристаллы старосте
2. Принять «Эхо руин»
3. Прокачаться до 15, Wolfcave → Ruins
4. Убить 5 скелетов/зомби/призраков → сдать старосте

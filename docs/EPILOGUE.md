# Эпилог — Осколки Печати

## После
Сдан `quest_ice_001` (Ледяная крепость) → староста даёт **Осколки Печати**.

## Цель
Принести **5× black_crystal** (как квест осколков после главаря).

## App
`complete_quest` для deliverItems уже должен снимать кристаллы с инвентаря
(как `quest_shards_001`). Если нет — см. CRYSTALS_QUEST.md.

Флаг: `crystalCount` в getNpcDialogue.
